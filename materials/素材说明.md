# 素材如何放置

材料统一放在 `D:\Projects\粤社多邻国\materials\`。题号固定，出场顺序调整不影响文件命名。目录已经建好，可以分批提供。

## 录音

- 翻译：放入 `翻译/T01` 至 `翻译/T05`，按每题词块顺序命名为 `01.m4a`、`02.m4a` 等。
- 配对：放入 `配对/M01` 或 `配对/M02`，每题四段：`01.m4a` 至 `04.m4a`。
- 熊二跟读：`跟读/S01-熊二.m4a`。
- 拽姐跟读：`跟读/S02-拽姐.m4a`。

MP3、M4A、WAV 均可。保持实际扩展名，例如录的是 MP3 就命名 `01.mp3`，不要仅修改扩展名冒充格式。同一编号只保留一个格式的文件。

每个词块一段录音，跟读每整句一段录音。手机原始录音即可，不必加背景音乐。若目前只能一次录完，保留长录音并注明顺序，交给开发者切分；接入脚本只接受已经分好的单段录音。

## 广告与二维码

- `广告/粤社广告.mp4`：15秒视频，建议9:16竖屏、720×1280或1080×1920，MP4使用H.264视频和AAC音频。
- `二维码/招新二维码.png`：清晰原图，保留四周白边；也支持同名 JPG/JPEG/WebP。

## 文字

在同目录的 `题目说明.txt` 中写明题号、普通话题干、粤语答案、粤拼、词块拆分及录音对应。允许的其他正确答案也一并写明。

当前题目文件已填入9道不重复的测试题，包含截图语料及浙大校园语料。按当前词块拆分，一共需要36段录音：翻译26段、配对8段、跟读2段。每个题号的具体文字与录音编号见 `题目说明.txt`；正式语料替换后，以新拆分为准。

## 交给网页使用

放好文件后，在项目根目录运行 `npm run materials`。脚本会将已提供的文件复制到 `dist/media`，并更新网页的素材清单。缺失材料继续显示占位状态。

题目说明的文字不会自动变成题库：需要同步编辑 `dist/content/course.js`，或交给开发者接入。这样可在上线前核对词块、粤拼、答案及录音是否一致。

替换后运行 `npm run check` 检查素材引用，再打开本地预览逐段试听。
