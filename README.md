# 粤社版多邻国 · 第二版

手机竖屏网页，按提供的多邻国截图布局。纯 HTML / CSS / JavaScript，无运行时依赖。未部署。

GitHub 仓库：<https://github.com/conscient2025/zju-cantonese-duolingo>（私有）。Ubuntu + Nginx 的具体步骤见 [部署说明](部署说明.md)，对应配置片段为 [deploy/yue-location.conf](deploy/yue-location.conf)。

## 本地预览

安装 Node.js 后，在项目目录运行 `npm start`，打开命令输出的本机地址（默认 http://127.0.0.1:4173）。不要直接双击 HTML，因为浏览器需要通过 HTTP 加载模块和素材清单。

如需手机在同一局域网访问，可自行设置环境变量 `YUE_PREVIEW_HOST=0.0.0.0` 后启动，并使用电脑的局域网 IP。默认只监听本机。

正式部署只需由现有服务器托管 `dist/` 静态文件。一个站点可供多人同时访问，每个页面独立维护答题、分数和计时，没有共享答题状态，也不需要为每个用户启动服务。实际并发容量取决于服务器、带宽和音视频文件大小；当前未做压力测试。

## 文件

- `dist/`：最终静态网页目录，可由你自行放到已有服务器的根目录或子目录。
- `dist/content/course.js`：9题内容、固定题号及可调整的出场顺序。
- `dist/content/media.json`：脚本生成的录音、广告和二维码对应清单。
- `materials/`：社员素材交付目录，详见其中的素材说明及题目说明。
- `dist/engine.js`：判题、一次错题重练、计分、计时及广告播放条件。
- `dist/game.js` / `dist/game.css`：交互及截图风格界面。

## 当前占位内容

9道题内容不重复。T01、T02、M01及熊二跟读保留截图语料；新增“我在浙大读书”“我们一起去紫金港”“下课后去吃饭吧”、校园词语配对，以及拽姐的“欢迎来浙大粤语社”。详见 `materials/题目说明.txt`。

新增内容用于测试，正式接入前可由社员校订和替换。没有伪造社员录音：缺音频时点击会提示对应词语和“录音待补充”。

广告未提供时显示明确标注的15秒占位演示，倒计时结束进入二维码待补充页。放入真实MP4后自动采用视频实际播放进度。最终二维码未提供时不生成虚假二维码。

## 规则

- 5翻译＋2配对（每题4组）＋2跟读。无限能量显示为 ∞。
- 翻译错误进入一次重练；重练再次错误也直接结束该题。
- 配对错误短暂变红，留在本题继续；已经配好的卡片保留。
- 跟读播放社员录音；不录音、不识别，提示读给现场工作人员听，点“继续”按通过处理。播放录音时角色没有额外动画。
- 9道主线题首次表现决定正确题数与正确率；配对题有过错误即不计整题正确，跟读通过计正确，重练不回改首次成绩。
- 每道翻译答对、整道配对四组全对、每道跟读继续使连击＋1；配对途中错误即归零，该题完成后也不加连击。重练也影响连击。
- 连击仅在答对后短暂动画显示，约1.65秒后消失。题目进度按18%、16%、14%、12%、10%、9%、8%、7%、6%递减增长，约0.7秒平滑过渡；这是参考视觉规律的实现，不是原版公式。翻译首答错误的进度在一次重练结束时补上。
- 用时包括答题、听音、反馈和重练，不含广告；切到后台暂停计时。
- 广告正常流程不可跳过/快进；暂停或切到后台不计播放时间，完整播放后显示二维码。

## 动画

保留截图中的原角色形象，通过 CSS 裁切窗口显示截图角色，再做轻微待机位移、正确反馈跳跃/已有姿态切换、错误摇头和庆祝动作。跟读角色保持静止，只保留气泡内播放按钮。翻译词块独立飞入/飞回，横线按实际行排列；系统开启减少动态效果时省略位移动画。

## 素材接入与检查

1. 按 `materials/素材说明.md` 放好文件。
2. 运行 `npm run materials`，将现有素材复制到 `dist/media/` 并更新清单。材料可分批加入。此命令不自动解读题目说明文字，也不会修改题目内容。
3. 替换正式语料时同步编辑 `dist/content/course.js`（或将题目说明交给开发者处理）。
4. 运行 `npm test` 和 `npm run check`。

本轮状态保存在当前页面内存中，刷新会重新开始。WebMCP 在支持的浏览器中可选注册，普通浏览器不依赖该接口。
