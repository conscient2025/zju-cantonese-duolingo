# 粤社版多邻国

浙江大学学生粤语社招新现场使用的手机粤语小游戏。界面参考提供的多邻国粤语课程截图，使用纯 HTML、CSS 和 JavaScript，无运行时依赖。

项目只维护一套当前代码，不使用版本编号。仓库为 [conscient2025/zju-cantonese-duolingo](https://github.com/conscient2025/zju-cantonese-duolingo)（私有）。

在线体验：**<https://conscient.hk.cn/yue/>**。

## 玩法

固定9道题：5道翻译、2道配对、2道跟读。题号固定，顺序可调整，当前测试题内容不重复。

- **翻译这句话**：点击粤语词块播放社员录音，词块飞入答案横线；再次点击可移回词库。提交后显示判题反馈。
- **选择配对**：每题4组粤语音频与普通话释义。配错后可继续，已完成配对保留；整题没有配错才计为正确。
- **跟着熊二／拽姐念**：各一道。播放示范录音后，用户读给现场工作人员听；工作人员口头确认后点击“继续”。不录音、不做语音识别或额外判分操作。
- **错题重练**：翻译首答错误在最后重练一次，再次答错也结束该题。
- **连击与进度**：连续答对整题才增加连击，答错归零；连击仅短暂显示。进度前几题增长较多、后面逐渐减小，采用平滑动画。能量显示为 ∞。
- **结束流程**：显示正确题数、正确率和用时，再播放不可跳过的15秒社团广告，完整播放后显示招新二维码。

成绩按9道主线题的首次表现计算，重练不修改首次成绩。跟读点击继续计为正确。用时包括重练、不含广告，页面进入后台时暂停计时。

## 本地运行

安装 Node.js，在项目目录执行：

```bash
npm start
```

打开终端提示的地址，默认是 <http://127.0.0.1:4173/>。项目不需要 `npm install` 或构建步骤；请通过 HTTP 预览，不要直接双击 HTML。

同一局域网手机测试时，可在 PowerShell 中执行：

```powershell
$env:YUE_PREVIEW_HOST = '0.0.0.0'
npm start
```

手机连接同一网络，再访问电脑的局域网 IP 和4173端口。默认启动方式只监听本机。

## 语料和素材

当前使用截图语料及浙大校园测试例句，正式录音、广告和招新二维码待粤语社提供。缺录音会提示待补充；缺广告时展示明确标注的15秒占位演示；缺二维码时展示待补充状态。

1. 按 [素材说明](materials/素材说明.md) 和 [题目及录音编号](materials/题目说明.txt) 放置材料。按当前词块拆分，共需要40段录音。
2. 运行 `npm run materials`，复制已提供的素材并生成网页素材清单。
3. 修改正式题干、粤拼、词块或允许答案时，编辑 `dist/content/course.js`；文本说明不会自动转换成题库。
4. 运行 `npm run check`，再打开页面试听和检查。

角色使用参考截图裁切，配合 CSS 姿态和位移动画；跟读角色保持静止。系统开启减少动态效果时省略词块等位移动画。

## 项目文件

| 路径 | 用途 |
| --- | --- |
| `dist/` | 可直接部署的静态网页及素材 |
| `dist/content/course.js` | 题库、词块、答案与出场顺序 |
| `dist/content/media.json` | 素材脚本生成的音视频及二维码清单 |
| `dist/engine.js` | 判题、重练、计分、计时和广告播放条件 |
| `dist/game.js`、`dist/game.css` | 页面交互与样式 |
| `materials/` | 社员素材交付说明和录音编号 |
| `scripts/`、`tests/` | 本地预览、素材接入和检查测试 |
| `deploy/yue-location.conf` | 现有 Nginx 博客站点使用的配置片段 |
| `scripts/ota.ps1`、`deploy/publish.py` | 手动上传更新、文件校验、切换和回退 |

## 部署与 SSH

已部署到 Ubuntu 服务器 `admin@118.178.91.193`，由现有 Nginx 提供 `https://conscient.hk.cn/yue/`，博客继续使用原有反代。服务器不需要运行 Node.js 预览服务。

- [SSH连接说明](SSH连接说明.md)：现有连接方式和密钥位置。
- [部署说明](部署说明.md)：实际服务器路径、手动 OTA、验收和回退。

在本机项目目录执行 `./scripts/ota.ps1` 即可手动更新；它只上传 `dist`，通过校验后切换网页，并保留一份更新前备份。修改语料素材后先运行 `npm run materials`。GitHub 推送不会自动触发部署。

每个用户的答题状态保存在各自页面内存中，刷新会重新开始，多人访问不会共享答题进度。实际并发容量取决于服务器带宽和音视频大小，尚未做压力测试。
